Preguntas frecuentes

¿Cómo se juega?

Toca o mantén la pantalla para subir y suelta para bajar. Las monedas suman puntos, pero llenan la burbuja: si se llena del todo, hace ¡plop! Atrapa chispas mágicas para desinflarla y busca las 3 plumas doradas para ganar la postal dorada.

¿Cómo abro más ciudades?

Cada vez que llegas a la meta de una ciudad se abre la siguiente. Con 3 estrellas (24 monedas y llegar a la meta) ganas el accesorio de esa ciudad.

¿Hay compras dentro de la app?

No. Todo se gana jugando: monedas, huesitos, accesorios y ayudas.

El juego va lento o se cerró

Ve a Ajustes → Gráficos y elige «Ahorro de batería». Si el juego se cierra en pleno vuelo, la siguiente vez se activa solo. Si sigue pasando, escríbenos con el modelo de tu iPhone.

¿Cómo borro mi progreso?

En Ajustes → Borrar mi progreso.
